>日志存储:文本文件 (后续可扩展到指定数据库 或者 服务器中)
>日志内容:时间、级别、文件、行号、内容 
>日志级别: debug < info < warn < error < fatal
>日志自动滚动: 设置单个日志文件大小 如10MB，超出自动创建新的文件
>异步IO：尽量不影响调用了输出日志功能的线程的效率。
>线程安全：可以多个线程同时输出日志。
>崩溃安全：保证崩溃前的日志可以输出到日志，最好在最后还自动输出崩溃时的堆栈
